# Инструкция: «Закладка в оснастку»

Программа строит пошаговую инструкцию закладки деталей в сварочную оснастку по сборке NX:
на каждом этапе видно, что уже лежит в оснастке, какую деталь класть сейчас и с какой стороны,
какие прижимы и пальцы задействованы. Результат — PDF, по листу на этап.

---

## 1. Что нужно

- Windows, установленный **NX** (лицензия на запуск журналов; окно NX открывать не нужно).
- Сборка операции в NX: оснастка и свариваемые детали **в одной сборке**, в рабочем положении
  (детали стоят там, где они лежат в оснастке).

## 2. Запуск

Программа поставляется папкой `Osnastka` (архив `Osnastka-<версия>.zip` на странице релизов
https://github.com/Mihail-Tsaletov/Osnastka/releases) — запускать `Osnastka.exe` внутри неё.
Python и другие программы ставить не нужно (кроме NX). Переносить **всю папку целиком** —
один `Osnastka.exe` без папки `_internal` не запустится.

Рекомендуемое место — папка пользователя, например `%LOCALAPPDATA%\Osnastka`
(вставьте это в адресную строку проводника). В `C:\Program Files` программа не сможет обновлять
сама себя без прав администратора. Ярлык на рабочем столе: правый клик по `Osnastka.exe` →
«Отправить» → «Рабочий стол (создать ярлык)».

Можно перетащить на `Osnastka.exe` (или на ярлык) файл сборки `.prt` или сценария `.weldviz.yaml` —
он откроется сразу.

### Обновления

При запуске программа сама проверяет, есть ли новая версия. Если есть — в правом нижнем углу
появляется красная кнопка **«Доступна версия X — обновить»**: нажмите, подтвердите — программа скачает
новую версию, закроется и через несколько секунд запустится уже обновлённой. Сценарии и модели
не затрагиваются. Проверить вручную — кнопка **Обновления** на верхней панели. Номер установленной
версии — в заголовке окна и в правом нижнем углу.

Если на компьютере нет доступа к github.com, администратор может выкладывать обновления в сетевую
папку: положите рядом с `Osnastka.exe` файл `update.json` с содержимым
`{"folder": "\\\\server\\share\\Osnastka"}` (путь к папке, куда выкладываются релизы).

## 3. Окно программы

```
┌──────────── панель: Открыть сборку · Открыть сценарий · Сохранить · Обновить из NX · Экспорт PDF ───┐
│ Состав сборки       │                    3D-вид текущего этапа                                     │
│ (дерево + роли)     │   (вращение — левая кнопка, сдвиг — Shift/средняя, масштаб — колесо)         │
│                     ├──────────────────────────────────────────────────────────────────────────────┤
│                     │ ◀ Предыдущий  Следующий ▶   + Этап в конец  − Этап   ☐ Показать всю сборку       │
│                     │ Этап N: [описание]   Закладка: [сверху ▾]  Запомнить ракурс  Сбросить ракурс   │
│                     │ Таблица: строки — детали и прижимы, столбцы — этапы                          │
└─────────────────────┴──────────────────────────────────────────────────────────────────────────────┘
```

## 4. Порядок работы

### Шаг 1. Открыть сборку

**Открыть сборку NX…** → выбрать `.prt` верхней сборки операции.

Программа в фоне запускает NX и выгружает состав сборки и геометрию — от нескольких секунд
до нескольких минут на больших сборках. Результат запоминается (папка `.weldviz` рядом со сборкой),
повторное открытие — мгновенное.

> Если сборку поменяли в NX, нажмите **Обновить из NX**. Изменение файла верхней сборки программа
> заметит сама, а изменения только в подсборках или деталях — нет.

### Шаг 2. Указать оснастку

Слева — дерево сборки, справа от каждого компонента его **роль**:

| Роль | Что значит | Как показывается |
|---|---|---|
| **Оснастка** | плита, опоры, упоры | серым, на всех этапах |
| **Прижим / подвижный** | прижимы, пальцы, откидные упоры, цилиндры | зелёным, только на отмеченных этапах |
| **Деталь** | свариваемая деталь | красным на этапе закладки, затем серо-синим |
| **Скрыть** | не нужно на картинках (крепёж, вспомогательное) | не показывается |

Программа сама угадывает головную подсборку оснастки (она выделена **жирным**, над деревом написан префикс).
Если угадала неверно — **правый клик** по головной детали оснастки → **«Основная деталь оснастки»**.
Тогда, например, для `0912-4410.000.01`:
- всё внутри этой подсборки и всё с префиксом `0912-4410` — оснастка;
- всё остальное — свариваемые детали.

Прижимы и пальцы определяются автоматически, если в обозначении или наименовании есть слова
*прижим, clamp, destaco, палец, фиксатор, pin, цилиндр*. Остальное — вручную:
**правый клик → «Роль: Прижим / подвижный»**. Роль, назначенная вручную, отмечена звёздочкой `*`;
вернуть автоматическую — «Роль: по умолчанию».

Роль подсборки действует на всё её содержимое: прижим-подсборка (корпус + рычаг) — одна строка в таблице.

### Шаг 3. Составить этапы

Внизу таблица: **строки** — детали (верхний блок) и прижимы (нижний блок), **столбцы** — этапы.

- **◀ Предыдущий / Следующий ▶** — перейти к соседнему этапу. На первом и последнем этапе
  соответствующая кнопка неактивна. Перейти можно и щелчком по любой ячейке или заголовку столбца.
- **+ Этап в конец** — добавить этап после последнего (прижимы копируются с последнего этапа).
  Можно нажимать с любого этапа — уже составленные этапы не сдвигаются.
- **− Этап** — удалить текущий.

**Правый клик по заголовку столбца этапа** — меню для изменения порядка:
- «Вставить новый этап после этапа N» — этап в середину; все следующие этапы сдвигаются на один номер
  вместе со своими деталями;
- «Поменять этап N местами с этапом N−1 / N+1» — этап переезжает **вместе со своими галочками**;
- «Удалить этап N».

> Переход между этапами — только **◀ Предыдущий / Следующий ▶** или щелчок по столбцу.
> Перестановка из меню меняет порядок закладки, а не текущий этап.

**Редактируется только текущий этап** — его номер в заголовке отмечен `▶` и жирный, пустые ячейки
светло-жёлтые. В 3D-окне вверху написано «Этап N из M — описание» — картинка всегда относится к нему.

Как работает щелчок по таблице:
- по ячейке **другого** этапа — только переход на этот этап, отметки не меняются
  (даже при двойном щелчке);
- по ячейке **текущего** этапа — поставить или снять отметку (щёлкать можно в любом месте ячейки).

Перетаскивание мышью по таблице и клавиши-стрелки этап не переключают.
Колесо мыши над списком «Закладка» направление не меняет — чтобы выбрать, раскройте список щелчком.

**Детали.** Галочка в строке детали на этапе закладки (красная ячейка) — деталь закладывается здесь.
У детали может быть только один этап закладки. На **следующих** этапах галочка (серо-синяя ячейка)
означает, что уже заложенная деталь **на месте**. Снятая галочка — деталь на этом этапе **убирается**:
на картинке она полупрозрачная, с тёмной стрелкой в ту сторону, откуда её закладывали, и попадает
в список «Убрать / открыть». Повторный щелчок — вернуть.
Новый этап, добавленный кнопкой «+ Этап в конец», скрывает те же детали, что и последний этап.
На этапах **до** закладки ячейка серая и не отмечается (подсказка покажет номер этапа закладки).
Чтобы перенести деталь на другой этап — перейдите на этап закладки, снимите галочку, вернитесь и поставьте её здесь.
Несколько деталей в одном столбце — **одновременная закладка**.
Детали, не попавшие ни в один этап, подсвечены **красным** в заголовке строки; в строке состояния — их количество.

**Прижимы.** Галочка — прижим виден (задействован) на этом этапе. Отметки задаются для каждого этапа
отдельно; удобнее всего расставить прижимы на этапе и затем добавлять следующие этапы кнопкой
**+ Этап в конец** — новый этап получит те же прижимы.
На этапе, где прижим появился впервые, на него указывает зелёная стрелка; на этапе, где он исчез,
он попадает в список «Убрать / открыть».

**Параметры этапа** (строка над таблицей):
- **Описание** — коротко, что делать: «Уложить поперечины». Попадает в заголовок листа PDF.
- **Закладка** — откуда подаётся деталь: сверху, снизу, спереди, сзади, слева, справа.
  Определяет направление красных стрелок.
- **Ракурс** — поверните модель в 3D-окне так, чтобы деталь этапа была хорошо видна.
  Вид **запоминается за этапом автоматически** при переходе на другой этап, сохранении и экспорте PDF;
  кнопка **Запомнить ракурс** делает то же сразу. Именно этот вид попадёт в PDF.
  Пока этап не поворачивали — используется общий изометрический вид («ракурс по умолчанию»).
  **Сбросить ракурс** — вернуть общий.

**Показать всю сборку** — временно показать всё сразу (удобно проверить роли).

### Шаг 4. Сохранить сценарий

**Сохранить** (Ctrl+S). Сценарий записывается рядом со сборкой: `<имя сборки>.weldviz.yaml`.
При следующем открытии этой сборки программа предложит его загрузить.
Звёздочка `*` в заголовке окна — есть несохранённые изменения.

### Шаг 5. Экспорт PDF

**Экспорт PDF…** → выбрать имя файла. Лист A4 альбомный на каждый этап:
- заголовок «Этап N из M — описание»;
- картинка с выбранного ракурса: закладываемые детали красным со стрелками и обозначениями,
  уже заложенные — серо-синим, прижимы этапа — зелёным (новые — с зелёной стрелкой), оснастка — серым;
- справа: список деталей с наименованиями, направление закладки, прижимы
  (`+` — появился на этом этапе), «Убрать / открыть» — прижимы, снятые по сравнению с прошлым
  этапом, и убранные детали. Убираемое показано на картинке полупрозрачным на своём месте
  с тёмной стрелкой: у прижима — вверх, у детали — туда, откуда её закладывали.

После формирования PDF откроется автоматически. Если PDF открыт в другой программе — закройте его перед повторным экспортом.

## 5. Пример: тестовая рама

В папке `test_frame` — сборка `FRAME_OPERATION.prt`: рама 2210-0035 на оснастке 0912-4410
(6 вертикальных прижимов, 2 пневмоприжима, 2 фиксирующих пальца, угловые упоры, опоры).

1. **Открыть сборку NX…** → `test_frame\FRAME_OPERATION.prt`.
2. Проверить, что над деревом написано «Оснастка: 0912-4410.000.01, префикс 0912-4410»,
   а прижимы и пальцы получили роль «Прижим / подвижный».
3. Этап 1, описание «Вставить пальцы, уложить лонжероны»: галочки у обоих `2210-0035.001`
   и у обоих пальцев `0912-4410.004`.
4. **+ Этап в конец** → «Уложить поперечины»: галочки у `2210-0035.002`, `2210-0035.002 (2)`, `2210-0035.003`.
5. **+ Этап в конец** → «Закрыть прижимы»: отметьте все прижимы `0912-4410.100` и `PNEUMO_DCL40`.
   Следующие этапы, добавленные кнопкой **+ Этап в конец**, получат эти отметки автоматически.
6. **+ Этап в конец** → «Установить косынки»: четыре `2210-0035.004`.
7. **+ Этап в конец** → «Установить проушины», Закладка: **спереди**; галочки у `2210-0035.005`;
   пальцы на этом этапе снимите — они уйдут в «Убрать / открыть».
8. **+ Этап в конец** → «Установить кронштейн»: `2210-0035.010`.
9. Пройти этапы кнопками **◀ Предыдущий / Следующий ▶** и на каждом повернуть вид как нужно —
   ракурс запомнится сам.
10. **Сохранить**, **Экспорт PDF…**.

## 6. Частые вопросы

**Деталь не отображается / пустая картинка.** Проверьте роль (не «Скрыть»?) и что деталь
отмечена в каком-либо этапе. Если компонент подавлен в NX, он не выгружается.

**В дереве не те детали / старая геометрия.** Нажмите **Обновить из NX**.

**Оснастка определилась как детали.** Выберите правильную основную деталь оснастки (шаг 2).

**Покупной прижим попал в «Оснастку».** Правый клик → «Роль: Прижим / подвижный».

**Ошибка «Не найден NX».** Программа ищет `run_journal.exe` по переменной `UGII_BASE_DIR`
и в `C:\Program Files\Siemens\*`. Проверьте, что NX установлен.

**Сценарий без интерфейса** (например, пересобрать PDF после изменения модели):
```
.venv\Scripts\python.exe -m weld_viz.cli сборка.weldviz.yaml --reexport
```

**Что хранится в сценарии.** Ссылка на сборку, головная деталь оснастки, роли, назначенные вручную,
этапы (детали, прижимы, направление, ракурс). Компоненты записаны путём в дереве сборки,
например `FRAME_OPERATION/0912-4410.000.01/0912-4410.100#2` (`#2` — второй экземпляр).
Если в NX переименовать или переставить компоненты, отметки этих компонентов в сценарии потеряются —
их нужно будет расставить заново.
