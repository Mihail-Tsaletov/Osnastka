# Инструкция: «Закладка в оснастку»

Программа строит пошаговую инструкцию закладки деталей в сварочную оснастку по сборке NX:
на каждом этапе видно, что уже лежит в оснастке, какую деталь класть сейчас и с какой стороны,
какие прижимы и пальцы задействованы. Результат — PDF, по листу на этап.

---

## 1. Что нужно

- Windows, установленный **NX** (лицензия на запуск журналов; окно NX открывать не нужно).
- Сборка операции в NX: оснастка и свариваемые детали **в одной сборке**, в рабочем положении
  (детали стоят там, где они лежат в оснастке).

## 2. Запуск

**Установщик** (страница релизов https://github.com/Mihail-Tsaletov/Osnastka/releases):
`Osnastka-Setup-<версия>.exe` — Windows 10/11, `Osnastka-win7-Setup-<версия>.exe` — Windows 7.
Запустите его (попросит права администратора — один раз) → «Установить». Программа встанет в
`C:\Program Files\Osnastka` для всех пользователей, появятся ярлыки «Закладка в оснастку» на рабочем столе
и в меню «Пуск». Удаление — «Программы и компоненты» (или `uninstall.exe` в папке программы); сценарии и
настройки пользователей при этом остаются. Для администраторов — тихая установка:
`Osnastka-Setup-<версия>.exe /S [/D=папка] [/NODESKTOP] [/NOSTARTMENU]`, удаление `uninstall.exe /S`.
Повторный запуск установщика более новой версии ставит её поверх прежней.

**Без установщика:** архив `Osnastka-<версия>.zip` — распакуйте папку `Osnastka` куда удобно (например
`%LOCALAPPDATA%`) и запускайте `Osnastka.exe` внутри неё. Переносить **всю папку целиком** — один
`Osnastka.exe` без папки `_internal` не запустится.

Python и другие программы ставить не нужно (кроме NX).

Можно перетащить на `Osnastka.exe` (или на ярлык) файл сборки `.prt` или сценария `.weldviz.yaml` —
он откроется сразу.

### Обновления

Программу ставят **один раз** (можно установщиком с правами администратора, можно в `C:\Program Files`).
Дальше она обновляется сама, без прав администратора и без запуска других программ: `Osnastka.exe`
не меняется, новая версия кода кладётся в профиль пользователя (`%LOCALAPPDATA%\Osnastka\app`)
и подхватывается при следующем запуске.

**Без интернета (рабочая сеть).** Обновление — один файл `Osnastka-update-<версия>.zip` (лежит в релизе
на GitHub, подходит и для Windows 10/11, и для Windows 7).
1. Положите его в папку обновлений — по умолчанию **«Документы\Osnastka\Обновления»** (можно сетевую
   папку: «Обновления» → «Изменить папку…»).
2. В программе нажмите **Обновления** на верхней панели → **«Установить»**. Или сразу
   **«Выбрать файл обновления…»** — тогда класть в папку не обязательно.
3. Программа перезапустится уже с новой версией. Сценарии и модели не затрагиваются.

Если файл обновления лежит в папке, при запуске в правом нижнем углу появится красная кнопка
**«Доступно обновление X — установить»**. Если доступ к github.com есть — в окне «Обновления» кнопка
**«Проверить GitHub»** скачает обновление сама.

Если новая версия почему-то не запустится, программа сообщит об этом и откроется со встроенной
версией (сведения об ошибке — в `%LOCALAPPDATA%\Osnastka\last_error.txt`). Вернуться на встроенную
версию вручную — **«Вернуть встроенную версию»** в окне «Обновления». Номер работающей версии — в
заголовке окна. Обновление меняет только код программы; если для новой версии нужен новый `Osnastka.exe`
(сменилась среда — Python, Qt, VTK), программа скажет, что архив не подходит, и тогда нужна переустановка.

## 3. Окно программы

```
┌──────────── панель: Открыть сборку · Открыть сценарий · Сохранить · Обновить из NX · Экспорт PDF ───┐
│ Состав сборки       │                    3D-вид текущего этапа                                     │
│ (дерево + роли)     │   (вращение — левая кнопка, сдвиг — Shift/средняя, масштаб — колесо)         │
│                     ├──────────────────────────────────────────────────────────────────────────────┤
│                     │ ◀ Предыдущий  Следующий ▶   + Этап в конец  − Этап   ☐ Показать всю сборку       │
│                     │ Этап N: [описание]   Закладка: [сверху ▾]  Запомнить ракурс  Сбросить ракурс   │
│                     │ Таблица: строки — детали и прижимы, столбцы — этапы                          │
└─────────────────────┴──────────────────────────────────────────────────────────────────────────────┘
```

## 4. Порядок работы

### Шаг 1. Открыть сборку

**Открыть сборку NX…** → выбрать `.prt` верхней сборки операции.

Программа в фоне запускает NX и выгружает состав сборки и геометрию — от нескольких секунд
до нескольких минут на больших сборках. Результат запоминается (кэш в `%LOCALAPPDATA%\Osnastka\cache` —
в папку модели программа ничего не пишет, она может быть только для чтения),
повторное открытие — мгновенное.

> Если сборку поменяли в NX, нажмите **Обновить из NX**. Изменение файла верхней сборки программа
> заметит сама, а изменения только в подсборках или деталях — нет.

#### Модель прямо из открытого NX (в том числе из Teamcenter)

Модель, открытую в NX, можно передать в программу кнопкой в самом NX — сохранять её в папку не нужно.
Работает и в обычном NX, и в NX с Teamcenter: программа определяет режим сама.

Журнал для этого — `%LOCALAPPDATA%\Osnastka\nx\osnastka_nx.cs` (C#, работает в NX 12 и новее; Python не
нужен). Программа кладёт его туда сама при каждом запуске, поэтому после обновления кнопка в NX сразу
работает с новым журналом — путь не меняется.
Настройка (один раз): в программе нажмите **«Кнопка в NX»** — путь к журналу скопируется в буфер обмена,
а в окне будет описано, как добавить кнопку на ленту NX. Без кнопки: в NX **Alt+F8** («Воспроизвести
журнал»; или вкладка «Разработка» → «Журнал» → «Воспроизвести») → «Обзор» → выбрать этот журнал →
**«Выполнить»**. NX запоминает последний журнал — потом достаточно Alt+F8 → «Выполнить». (Ctrl+U не подходит:
он не запускает Python.) Программу нужно хотя бы раз запустить на компьютере.

Дальше: открыли сборку в NX → нажали кнопку → модель выгружается (NX на это время занят, от нескольких
секунд до минуты) и открывается в программе; если программа не запущена — она запустится сама.

- Из обычного NX модель попадает в тот же кэш, что и при открытии из программы (в папку модели ничего не пишется).
- Из Teamcenter — в `%LOCALAPPDATA%\Osnastka`, сценарий по умолчанию сохраняется в «Документы\Osnastka».
  Обновить такую модель после изменений можно только той же кнопкой в NX.
- Выгружается то, что загружено в NX: если NX подтянул из Teamcenter стандартные изделия, они тоже попадут
  в модель.

### Шаг 2. Указать оснастку

Слева — дерево сборки, справа от каждого компонента его **роль**:

| Роль | Что значит | Как показывается |
|---|---|---|
| **Оснастка** | плита, опоры, упоры | серым, на всех этапах |
| **Прижим / подвижный** | прижимы, пальцы, откидные упоры, цилиндры | зелёным, только на отмеченных этапах |
| **Деталь** | свариваемая деталь | красным на этапе закладки, затем серо-синим |
| **Скрыть** | не нужно на картинках (крепёж, вспомогательное) | не показывается |

Программа сама угадывает головную подсборку оснастки (она выделена **жирным**, над деревом написан префикс).
Если угадала неверно — **правый клик** по головной детали оснастки → **«Основная деталь оснастки»**.
Тогда, например, для `0912-4410.000.01`:
- всё внутри этой подсборки и всё с префиксом `0912-4410` — оснастка;
- всё остальное — свариваемые детали.

Прижимы и пальцы определяются автоматически, если в обозначении или наименовании есть слова
*прижим, clamp, destaco, палец, фиксатор, pin, цилиндр*. Остальное — вручную:
**правый клик → «Роль: Прижим / подвижный»**. Роль, назначенная вручную, отмечена звёздочкой `*`;
вернуть автоматическую — «Роль: по умолчанию».

Роль подсборки действует на всё её содержимое: прижим-подсборка (корпус + рычаг) — одна строка в таблице.

Выделять можно сразу несколько строк (Ctrl — по одной, Shift — диапазон): роль назначится всем выбранным.
Выбранное подсвечивается в 3D синим, двойной щелчок — приблизить к нему.

#### Если стандартные изделия не загрузились

Программа ищет файлы компонентов в папке сборки и её подпапках. Стандартные и покупные изделия, которые
лежат на сервере компании (винты, шайбы, штифты, покупные прижимы), туда обычно не скопированы — такие
компоненты пропускаются, сборка открывается без них. Над деревом появится пометка «Без N незагруженных
компонентов», список — во всплывающей подсказке.

#### «Шоп»-файл: оснастка и деталь в одной детали

Если открыть не сборку, а одну деталь, в которой оснастка и деталь лежат отдельными телами («шоп»-файл),
каждое тело становится строкой дерева (`Body12` и т.п., цветной квадратик — цвет тела в NX). По умолчанию
**все тела — оснастка**. Чтобы получить деталь или прижим:

1. выделите в дереве тела, из которых он состоит (Ctrl/Shift; подсвеченное видно в 3D);
2. правый клик → **«Объединить в группу…»** и дайте имя, например «Прижим 1» или «Косынка»;
   если в имени есть слово «прижим», «палец» и т.п. — группа сразу станет прижимом;
3. при необходимости задайте группе роль (правый клик → «Роль: Деталь»).

Группа — одна строка в таблице этапов. По умолчанию она получает роль своих членов (группа из прижимов —
прижим), отметки этапов её членов переходят на группу. Группы можно переименовать и разгруппировать
(правый клик по группе), они сохраняются в сценарии.

#### Разобрать узел на детали

Свариваемый узел обычно приходит одной строкой — например, «шоп»-деталь `S300.14.02.010A…-shop`, в которой
каждое тело — отдельная деталь узла. Чтобы закладывать детали по очереди: правый клик по узлу →
**«Разобрать на составляющие»**. Каждое тело (или компонент подсборки) станет отдельной строкой таблицы,
пока нигде не заложенной — распределите детали по этапам щелчком по клетке нужного этапа.
**«Собрать обратно»** — снова одна строка.

Мелочь, которую не нужно показывать (сварные швы, метки): правый клик по такому телу в дереве →
**«Выделить тела того же цвета»** → правый клик → **«Роль: Скрыть»** (или объедините их в группу и скройте её).

Перенести деталь на другой этап: перейдите на нужный этап, правый клик по клетке детали →
**«Закладывать на этапе N (перенести с этапа M)»**.

#### Заменить «шоп»-деталь нормальной сборкой узла

Если у узла есть отдельный файл `.prt` с деревом компонентов (детали с обозначениями и наименованиями),
его можно подставить вместо «шоп»-детали: правый клик по узлу → **«Заменить деталью из файла…»** →
выбрать `.prt` узла.

Если узел хранится в Teamcenter или его удобнее открыть в NX — правый клик по узлу → **«Заменить деталью
из открытого NX…»**. Программа будет ждать (внизу окна надпись «Ждём из NX деталь…» и кнопка
«Отменить ожидание»): откройте в NX нормальную сборку узла и нажмите кнопку Osnastka (Alt+F8 → журнал
`osnastka_nx.cs`). Пришедшая деталь не откроется как новая модель, а встанет вместо выбранного узла —
так можно заменить любую конкретную «шоп»-деталь, остальные не затрагиваются. Замена из Teamcenter
запоминается в сценарии; если кэш программы очистят, снова откройте деталь в NX и нажмите кнопку.

- Программа выгрузит файл из NX и **сама совместит** его с телами «шоп»-детали по форме деталей — неважно,
  в какой системе координат он сделан. Итог покажет: «совпало 13 из 13 деталей, отклонение до 0,00 мм».
  Если совпало не всё, программа спросит, ставить ли всё равно; если не совпало ничего — откажет
  (скорее всего, выбран файл другого узла).
- Вместо `Body…` в таблице этапов появятся детали узла с их обозначениями и наименованиями — распределите
  их по этапам.
- Исходные файлы NX не меняются, замена хранится в сценарии. **«Вернуть исходную деталь»** (правый клик
  по узлу) — отменить замену.

Чтобы понять, какое тело есть какое: щёлкните по названию строки в таблице или по строке в дереве — тело
подсветится в 3D синим (цвет тела в NX — во всплывающей подсказке строки дерева).

#### Окно «Выбор по модели»

Кнопка **«Окно выбора»** вверху открывает отдельное окно со всей моделью (цвета ролей: деталь — красный,
прижим — зелёный, оснастка — серый). Его удобно держать рядом с основным окном:

- **щелчок по детали** — она выбирается в дереве и в таблице этапов (таблица прокручивается к её строке);
  **Ctrl+щелчок** — добавить к выбору; щелчок по пустому месту — снять выбор. Вращать модель — как обычно,
  перетаскиванием; это щелчком не считается;
- при наведении внизу окна написано, что под курсором и в состав чего оно входит;
- **«Выбирать»**: «как в таблице» — щелчок выбирает строку таблицы целиком (деталь, прижим, группу);
  «отдельный компонент / тело» — конкретную деталь или тело (например, чтобы собрать группу);
- **«На текущий этап»** — выбранные детали закладываются на текущем этапе, прижимы показываются на нём;
  **«Снять с этапа»** — обратно; **«Роль…»** и **«В группу…»** — как в контекстном меню дерева;
- **«Оснастка полупрозрачная» / «Скрыть оснастку»** — чтобы добраться до деталей внутри оснастки;
- **погасить мешающие детали** (например, когда на оснастке лежат сразу несколько деталей и они накладываются):
  правый щелчок по детали → **«Скрыть «…»»** или **«Оставить только «…»»**; кнопки **«Скрыть выбранное»**,
  **«Показать только выбранное»**, **«Показать всё»**. Скрытое не мешает щелчку — выбирается то, что за ним.
  Это действует только на окно выбора: роли, этапы и картинки PDF не меняются;
- выбор работает в обе стороны: выбрали строку в дереве основного окна — она подсветится и здесь.

### Шаг 3. Составить этапы

Внизу таблица: **строки** — детали (верхний блок) и прижимы (нижний блок), **столбцы** — этапы.

- **◀ Предыдущий / Следующий ▶** — перейти к соседнему этапу. На первом и последнем этапе
  соответствующая кнопка неактивна. Перейти можно и щелчком по любой ячейке или заголовку столбца.
- **+ Этап в конец** — добавить этап после последнего (прижимы копируются с последнего этапа).
  Можно нажимать с любого этапа — уже составленные этапы не сдвигаются.
- **− Этап** — удалить текущий.

**Правый клик по заголовку столбца этапа** — меню для изменения порядка:
- «Вставить новый этап после этапа N» — этап в середину; все следующие этапы сдвигаются на один номер
  вместе со своими деталями;
- «Поменять этап N местами с этапом N−1 / N+1» — этап переезжает **вместе со своими галочками**;
- «Удалить этап N».

> Переход между этапами — только **◀ Предыдущий / Следующий ▶** или щелчок по столбцу.
> Перестановка из меню меняет порядок закладки, а не текущий этап.

**Редактируется только текущий этап** — его номер в заголовке отмечен `▶` и жирный, пустые ячейки
светло-жёлтые. В 3D-окне вверху написано «Этап N из M — описание» — картинка всегда относится к нему.

Как работает щелчок по таблице:
- по ячейке **другого** этапа — только переход на этот этап, отметки не меняются
  (даже при двойном щелчке);
- по ячейке **текущего** этапа — поставить или снять отметку (щёлкать можно в любом месте ячейки).

Перетаскивание мышью по таблице и клавиши-стрелки этап не переключают.
Колесо мыши над списком «Закладка» направление не меняет — чтобы выбрать, раскройте список щелчком.

**Детали.** Галочка в строке детали на этапе закладки (красная ячейка) — деталь закладывается здесь.
У детали может быть только один этап закладки. На **следующих** этапах галочка (серо-синяя ячейка)
означает, что уже заложенная деталь **на месте**. Снятая галочка — деталь на этом этапе **убирается**:
на картинке она полупрозрачная, с тёмной стрелкой в ту сторону, откуда её закладывали, и попадает
в список «Убрать / открыть». Повторный щелчок — вернуть.
Новый этап, добавленный кнопкой «+ Этап в конец», скрывает те же детали, что и последний этап.
На этапах **до** закладки ячейка серая и не отмечается (подсказка покажет номер этапа закладки).
Чтобы перенести деталь на другой этап — перейдите на этап закладки, снимите галочку, вернитесь и поставьте её здесь.
Несколько деталей в одном столбце — **одновременная закладка**.
Детали, не попавшие ни в один этап, подсвечены **красным** в заголовке строки; в строке состояния — их количество.

**Прижимы.** Галочка — прижим виден (задействован) на этом этапе. Отметки задаются для каждого этапа
отдельно; удобнее всего расставить прижимы на этапе и затем добавлять следующие этапы кнопкой
**+ Этап в конец** — новый этап получит те же прижимы.
На этапе, где прижим появился впервые, на него указывает зелёная стрелка; на этапе, где он исчез,
он попадает в список «Убрать / открыть».

**Параметры этапа** (строка над таблицей):
- **Описание** — коротко, что делать: «Уложить поперечины». Попадает в заголовок листа PDF.
- **Закладка** — откуда подаётся деталь: сверху, снизу, спереди, сзади, слева, справа.
  Определяет направление красных стрелок.
- **Ракурс** — поверните модель в 3D-окне так, чтобы деталь этапа была хорошо видна.
  Вид **запоминается за этапом автоматически** при переходе на другой этап, сохранении и экспорте PDF;
  кнопка **Запомнить ракурс** делает то же сразу. Именно этот вид попадёт в PDF.
  Пока этап не поворачивали — используется общий изометрический вид («ракурс по умолчанию»).
  **Сбросить ракурс** — вернуть общий.

**Показать всю сборку** — временно показать всё сразу (удобно проверить роли).

**Цвета: по ролям / как в NX** (рядом с «Показать всю сборку») — в режиме «как в NX» оснастка, уже
заложенные детали и прижимы рисуются своими цветами из NX (с учётом цветов, назначенных в сборке);
закладываемая деталь остаётся красной с толстым контуром, стрелки и убираемое — цветами инструкции.
Режим сохраняется в сценарии и действует на PDF.

### Шаг 4. Сохранить сценарий

**Сохранить** (Ctrl+S). Сценарий записывается в **«Документы\Osnastka\Сценарии»**:
`<имя сборки>.weldviz.yaml` (папка модели может быть только для чтения, а «Документы» доступны всегда).
При открытии модели программа сама ищет её сценарии — сначала для той же модели (по полному пути), потом для
модели с таким же именем из другой папки — и предлагает открыть; если сценариев несколько — даёт выбрать.
Старые сценарии, сохранённые рядом с моделью версиями до 0.4, тоже находятся.
При следующем открытии этой сборки программа предложит его загрузить.
Звёздочка `*` в заголовке окна — есть несохранённые изменения.

#### Уточнения на листе: крупный вид элемента

Если на общем виде этапа мелкая деталь плохо видна, добавьте на тот же лист **окошко с крупным видом**
(уточнение). Строка **«Уточнения на листе»** под описанием этапа:

1. Выделите элемент в дереве или щёлкните по строке таблицы (подсветится синим) и нажмите
   **«+ Уточнение»** — 3D-вид сам наведётся на него крупно. Без выделения — приблизьте нужное место
   сами (колесо мыши, поворот).
2. Проверьте вид в 3D и нажмите **«Готово»** (или «Отмена»). Вид этапа вернётся, а откроется окно
   **«Компоновка листа»** — лист этапа таким, каким он выйдет в PDF.
3. В компоновке **перетащите окошко** мышью куда нужно, **размер** — за синий уголок справа внизу.
   «Расставить по углам» — разнести окошки по свободным углам картинки. Правый клик по окошку —
   подпись («Вид А: крепление проушины»), обводка места на общем виде, удалить.

На общем виде место уточнения обводится синим кругом с буквой (А, Б, В…) и соединяется с окошком
пунктиром (синим — чтобы не путать с красными закладываемыми деталями). Круг в «Компоновке листа» тоже
правится: **перетащите** его за середину или за букву, **размер** — потяните за край круга. Правый клик →
«Обводка — снова по виду уточнения» вернёт круг на место. Если потом изменить вид уточнения в 3D, круг снова
встанет по новому виду. Уточнений на листе может быть несколько. Каждое — кнопка «Вид А…» в строке «Уточнения на
листе»: изменить вид в 3D, подпись, обводка, компоновка, удалить. Обводку можно выключить, если окошко —
не крупный план, а просто другой ракурс этапа.

#### Стрелки: переместить вручную

Если стрелка закрывает что-то важное или подпись налезает на другую — откройте **«Компоновка листа…»**
(кнопка доступна на любом этапе, уточнения не нужны). На концах стрелок деталей, прижимов и убираемого —
ручки:
- **квадратик** у детали — перетащить **всю стрелку** (вместе с подписью);
- **кружок** на свободном конце, у подписи, — повернуть стрелку и изменить длину; конец у детали остаётся
  на месте.

Стрелка сдвигается в пространстве, поэтому так же сдвинется и в окошках уточнений, и в 3D-виде программы,
и в PDF. Правый клик по ручке — «Стрелка … — как по умолчанию»; кнопка **«Стрелки по умолчанию»** —
вернуть все стрелки этапа.

### Шаг 5. Экспорт PDF

**Экспорт PDF…** → выбрать имя файла. Лист A4 альбомный на каждый этап:
- заголовок «Этап N из M — описание»;
- картинка с выбранного ракурса: закладываемые детали красным со стрелками и обозначениями,
  уже заложенные — серо-синим, прижимы этапа — зелёным (новые — с зелёной стрелкой), оснастка — серым;
- справа: список деталей с наименованиями, направление закладки, прижимы
  (`+` — появился на этом этапе), «Убрать / открыть» — прижимы, снятые по сравнению с прошлым
  этапом, и убранные детали. Убираемое показано на картинке полупрозрачным на своём месте
  с тёмной стрелкой: у прижима — вверх, у детали — туда, откуда её закладывали;
- окошки уточнений поверх картинки — там, где их расставили в «Компоновке листа».

После формирования PDF откроется автоматически. Если PDF открыт в другой программе — закройте его перед повторным экспортом.

## 5. Пример: тестовая рама

В папке `test_frame` — сборка `FRAME_OPERATION.prt`: рама 2210-0035 на оснастке 0912-4410
(6 вертикальных прижимов, 2 пневмоприжима, 2 фиксирующих пальца, угловые упоры, опоры).

1. **Открыть сборку NX…** → `test_frame\FRAME_OPERATION.prt`.
2. Проверить, что над деревом написано «Оснастка: 0912-4410.000.01, префикс 0912-4410»,
   а прижимы и пальцы получили роль «Прижим / подвижный».
3. Этап 1, описание «Вставить пальцы, уложить лонжероны»: галочки у обоих `2210-0035.001`
   и у обоих пальцев `0912-4410.004`.
4. **+ Этап в конец** → «Уложить поперечины»: галочки у `2210-0035.002`, `2210-0035.002 (2)`, `2210-0035.003`.
5. **+ Этап в конец** → «Закрыть прижимы»: отметьте все прижимы `0912-4410.100` и `PNEUMO_DCL40`.
   Следующие этапы, добавленные кнопкой **+ Этап в конец**, получат эти отметки автоматически.
6. **+ Этап в конец** → «Установить косынки»: четыре `2210-0035.004`.
7. **+ Этап в конец** → «Установить проушины», Закладка: **спереди**; галочки у `2210-0035.005`;
   пальцы на этом этапе снимите — они уйдут в «Убрать / открыть».
8. **+ Этап в конец** → «Установить кронштейн»: `2210-0035.010`.
9. Пройти этапы кнопками **◀ Предыдущий / Следующий ▶** и на каждом повернуть вид как нужно —
   ракурс запомнится сам.
10. **Сохранить**, **Экспорт PDF…**.

## 6. Частые вопросы

**Деталь не отображается / пустая картинка.** Проверьте роль (не «Скрыть»?) и что деталь
отмечена в каком-либо этапе. Если компонент подавлен в NX, он не выгружается.

**В дереве не те детали / старая геометрия.** Нажмите **Обновить из NX**.

**Оснастка определилась как детали.** Выберите правильную основную деталь оснастки (шаг 2).

**Покупной прижим попал в «Оснастку».** Правый клик → «Роль: Прижим / подвижный».

**Ошибка «Не найден NX».** Программа ищет `run_journal.exe` по переменной `UGII_BASE_DIR`
и в `C:\Program Files\Siemens\*`. Проверьте, что NX установлен.

**Сценарий без интерфейса** (например, пересобрать PDF после изменения модели):
```
.venv\Scripts\python.exe -m weld_viz.cli сборка.weldviz.yaml --reexport
```

**Что хранится в сценарии.** Ссылка на сборку, головная деталь оснастки, роли, назначенные вручную,
этапы (детали, прижимы, направление, ракурс). Компоненты записаны путём в дереве сборки,
например `FRAME_OPERATION/0912-4410.000.01/0912-4410.100#2` (`#2` — второй экземпляр).
Если в NX переименовать или переставить компоненты, отметки этих компонентов в сценарии потеряются —
их нужно будет расставить заново.
