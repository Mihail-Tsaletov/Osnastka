# Закладка в оснастку

Визуализация пошаговой закладки деталей в сварочную оснастку по сборке NX.

## Запуск

`run.bat`. При первом запуске создаётся `.venv` и ставятся зависимости (нужен Python 3.12, `py -3.12`).
Можно передать файл: `run.bat сборка.prt` или `run.bat сценарий.weldviz.yaml`.

Нужен установленный NX (используется `run_journal.exe` из `%UGII_BASE_DIR%\NXBIN`).

## Как это работает

1. **Экспорт из NX** (`nx/export_assembly.py`, без GUI NX): дерево компонентов и сетка (STL) каждого компонента
   в `<папка сборки>/.weldviz/<имя>/`. Повторно выполняется, если изменилась дата файла верхней сборки,
   или по кнопке «Обновить из NX» (если меняли только подсборки).
2. **Роли компонентов.** Правый клик по детали оснастки → «Основная деталь оснастки»: всё внутри неё и всё с тем же
   префиксом обозначения (`0898-8264.000.01` → `0898-8264`) — оснастка. Остальное — свариваемые детали.
   Прижимы, пальцы и т.п. определяются по словам в имени (прижим, clamp, destaco, палец…) или назначаются вручную
   («Роль: Прижим / подвижный»).
3. **Этапы.** Таблица: строки — детали и прижимы, столбцы — этапы. Деталь отмечается на одном этапе (закладка),
   прижим — на всех этапах, где он виден. Редактируется только текущий (выбранный) этап.
   Для этапа задаются описание, направление закладки (стрелки) и ракурс («Запомнить ракурс»).
4. **Сценарий** сохраняется в `<сборка>.weldviz.yaml` рядом со сборкой.
5. **Экспорт PDF**: A4 альбом, лист на этап.

Без интерфейса: `.venv\Scripts\python.exe -m weld_viz.cli сценарий.yaml [-o out.pdf] [--reexport]`

Подробно для технолога — [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Тестовые модели

- `test_model/` — простая сборка из блоков и готовый сценарий (`nx\build_test_assembly.py`).
- `test_frame/` — рама на оснастке: цилиндрические пальцы, повёрнутые прижимы, наименования в атрибутах
  `DB_PART_NAME` (`nx\build_frame_assembly.py`). Сценария нет — его составляют по примеру из инструкции.

Пересоздать: `run_journal.exe nx\build_frame_assembly.py -args test_frame`
