# Osnastka

Программа помогает технологу показать, **в каком порядке закладывать детали в сварочную оснастку**.

Вы открываете сборку из NX, отмечаете, что кладётся на каждом шаге и какие прижимы закрываются, — а программа
рисует картинки по этапам и собирает из них понятную PDF-инструкцию: что уже лежит в оснастке, какую деталь
класть сейчас, с какой стороны и что нужно убрать.

---

## Как установить

**1. Скачайте установщик.** Зайдите на страницу
[последней версии](https://github.com/Mihail-Tsaletov/Osnastka/releases/latest) и в самом низу,
в разделе **Assets**, скачайте **`Osnastka-Setup-….exe`** (около 200 МБ).
Для **Windows 7** — **`Osnastka-win7-Setup-….exe`** (отдельная сборка на Qt 5).

Там же будут файлы «Source code» — их качать не нужно, это исходники для разработчиков.

**2. Запустите установщик** — он один раз попросит права администратора — и нажмите «Установить».
Программа встанет в `C:\Program Files\Osnastka` для всех пользователей, на рабочем столе и в меню «Пуск»
появится ярлык **«Закладка в оснастку»**. Удалить — через «Программы и компоненты».

Без прав администратора можно взять архив **`Osnastka-…zip`** (`Osnastka-win7-…zip` для Windows 7),
распаковать папку `Osnastka` куда удобно и запускать `Osnastka.exe` из неё.

Что нужно на компьютере: Windows 10/11 (или Windows 7 SP1 — архив `win7`) и установленный NX (NX 12 и новее). Сам NX открывать не надо — программа
запускает его в фоне, когда ей нужно прочитать сборку.

Пара важных мелочей:
- права администратора нужны только для установки: обновления потом ставятся из самой программы
  в профиль пользователя, без прав администратора;
- если ставили из архива — держите `Osnastka.exe` вместе с папкой `_internal`, по отдельности программа
  не запустится.

## Обновления

Обновление — файл `Osnastka-update-<версия>.zip` из релиза (один для Windows 10/11 и Windows 7).
Положите его в папку **«Документы\Osnastka\Обновления»** (или укажите другую, можно сетевую) и нажмите
в программе **«Обновления» → «Установить»**; либо **«Выбрать файл обновления…»** и укажите архив где угодно.
Программа перезапустится с новой версией — ни прав администратора, ни запуска других программ не нужно.
Если файл уже лежит в папке, при запуске в правом нижнем углу появится красная кнопка
**«Доступно обновление … — установить»**. Есть доступ к GitHub — кнопка **«Проверить GitHub»** скачает
обновление сама. Сценарии и модели при этом не трогаются; если новая версия не запустится, программа
откроется со встроенной.

## Как пользоваться

### 1. Откройте сборку

Нажмите **«Открыть сборку NX»** и выберите `.prt` сборки операции — той, где вместе лежат оснастка
и свариваемые детали, причём детали стоят на своих местах. В первый раз программа будет читать сборку
из NX — это займёт от нескольких секунд до пары минут. Дальше открывается сразу.

Модель можно передать и **прямо из открытого NX** — в том числе из NX с Teamcenter, ничего не сохраняя
локально. Как подключить кнопку в NX, программа подскажет сама: кнопка **«Кнопка в NX»** вверху.

### 2. Проверьте, где оснастка

Слева — состав сборки. Программа сама находит оснастку по обозначению: если головная деталь оснастки
`0898-8264.000.01`, то всё, что начинается на `0898-8264`, — это оснастка, а остальное — детали,
которые вы будете закладывать. Прижимы, пальцы и упоры она узнаёт по наименованию.

Если программа ошиблась, щёлкните правой кнопкой по нужной детали и выберите:
- **«Основная деталь оснастки»** — если неправильно определилась сама оснастка;
- **«Роль: …»** — чтобы сказать, что это: оснастка, прижим, деталь или что-то лишнее, что лучше скрыть.

### 3. Расставьте этапы

Внизу таблица: в строках — детали и прижимы, в столбцах — этапы.

Работаете всегда с одним, **текущим этапом** — у него в заголовке значок `▶`. Щёлкаете по клеткам
этого столбца — ставите или снимаете отметки. Щелчок по другому столбцу просто переносит вас на тот этап.

- **Детали.** Отметьте деталь на том этапе, где её кладут, — клетка станет красной. Можно отметить
  несколько деталей сразу, если их кладут одновременно. На следующих этапах у детали тоже стоит отметка —
  это значит «деталь на месте». Если на каком-то этапе деталь нужно снять, уберите отметку там.
- **Прижимы.** Отметьте прижим на тех этапах, где он закрыт. Убрали отметку — на картинке появится
  подсказка, что прижим нужно открыть.
- Над таблицей впишите **описание этапа** («Установить косынки») и выберите, **откуда кладут деталь** —
  сверху, спереди, сбоку. По этому рисуются стрелки.

Переходить между этапами — кнопками **«◀ Предыдущий»** и **«Следующий ▶»**. Новый этап —
**«+ Этап в конец»**, он сразу получит те же прижимы, что и последний. Если нужно вставить этап в середину,
поменять этапы местами или удалить — щёлкните правой кнопкой по заголовку этапа.

### 4. Выберите вид

Поверните модель в окне сверху так, чтобы на этом этапе всё было хорошо видно
(левая кнопка мыши — вращать, колесо — приблизить). Программа запомнит этот вид за этапом,
и именно он попадёт в PDF.

### Крупный вид мелкой детали на листе

Выделите деталь и нажмите **«+ Уточнение»** (строка «Уточнения на листе»): на лист этапа добавится окошко
с её крупным видом, а на общем виде место обведётся синим кругом с буквой. В **«Компоновке листа»** окошко
и круг перетаскиваются мышью, размер окошка — за уголок, круга — за край. Там же можно передвинуть стрелки
деталей и прижимов: за квадратик у детали — всю стрелку, за кружок у подписи — повернуть и изменить длину.
Как расставите, так и выйдет в PDF.

### 5. Сохраните и получите PDF

**«Сохранить»** (Ctrl+S) — сценарий сохранится в «Документы\Osnastka\Сценарии». В папку с моделью программа
ничего не пишет (она может быть только для чтения). Когда снова откроете эту модель, программа сама найдёт
её сценарий и предложит открыть.
**«Экспорт PDF»** — программа соберёт инструкцию и сразу её откроет.

### Что означают цвета

- **красный** со стрелкой — деталь, которую кладут на этом этапе;
- **серо-синий** — детали, которые уже лежат;
- **зелёный** — прижимы и подвижные элементы, новые — со стрелкой;
- **серый** — сама оснастка;
- **полупрозрачный** с тёмной стрелкой — то, что на этом этапе нужно убрать или открыть.

Переключатель **«Цвета: как в NX»** рисует оснастку и детали их цветами из NX — красной остаётся только
деталь, которую кладут на этом этапе.

Подробнее, с разобранным примером, — в [инструкции](ИНСТРУКЦИЯ.md).

## Если что-то пошло не так

**Поменяли сборку в NX, а в программе всё по-старому.** Нажмите «Обновить из NX» — программа
перечитает сборку заново.

**Пишет «Не найден NX».** Значит, на компьютере не нашёлся установленный NX. Программа ищет его
в `C:\Program Files\Siemens`.

**Закрыт доступ к GitHub, обновления не приходят.** Принесите файл `Osnastka-update-<версия>.zip`
и положите его в папку обновлений (см. «Обновления» выше) или укажите сетевую папку, куда их выкладывают:
«Обновления» → «Изменить папку…».

## Для разработчиков

Запуск из исходников — `run.bat` (нужен Python 3.12, окружение создастся само). Собрать exe —
`build_exe.bat`, результат в `dist\Osnastka`. Выпустить новую версию — `release.bat 0.3.0 "что нового"`:
скрипт поднимет номер версии, соберёт exe и архив, сделает коммит и тег, отправит их на GitHub
и опубликует релиз (нужен `gh auth login`). Для сетевой папки добавьте `--folder \\server\share\Osnastka`. Кроме exe-архивов релиз содержит
`Osnastka-update-<версия>.zip` — только код (`weld_viz/*.py` + журнал NX); его ставят из программы без прав
администратора, отдельно собрать — `make_update.bat`. Загрузчик `osnastka.py` берёт код из
`%LOCALAPPDATA%\Osnastka\app\v<версия>`, если он новее встроенного. Номер среды `RUNTIME` в `osnastka_build.py`
поднимайте, когда меняются зависимости: тогда обновление кодом невозможно и нужен новый exe.

Установщики — `make_installer.bat` → `dist\Osnastka-Setup-<версия>.exe` и `dist\Osnastka-win7-Setup-<версия>.exe`
(после сборки exe; `release.bat` делает их сам). Установщик — `installer/setup_stub.py`, собранный Python 3.8
(`.venv38`, PySide2 — запускается и на Windows 7), + zip готовой сборки, дописанный в конец exe.

Сборка для Windows 7 — `build_exe_win7.bat` → `dist_win7\Osnastka`: Python 3.8 (последний с поддержкой Win7;
переносная версия из пакета NuGet `python` 3.8.10 в папке `.py38`) + окружение `.venv38` из `requirements_win7.txt`
(PySide2 / Qt 5.15, VTK 9.2). Если `.venv38` есть, `release.bat` собирает и выкладывает оба архива.
Код общий: Qt подключается через `qtpy` (PySide6 или PySide2 — что установлено).

PDF без интерфейса: `.venv\Scripts\python.exe -m weld_viz.cli сценарий.yaml`.

Где что лежит: `nx/osnastka_nx.cs` — журнал NX на C# (выгрузка файла и кнопка в открытом NX; лежит рядом с программой, NX 12 и новее), `nx/build_*.py` — тестовые модели, `weld_viz/` — сама программа
(`app.py` — окно, `scene.py` — 3D, `pdf_report.py` — PDF, `updater.py` — обновления, `theme.py` — оформление).
Тестовые сборки — `test_model/` и `test_frame/`.
